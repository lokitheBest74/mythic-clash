MYTHIC CLASH: RIFTFALL — deployment

1. In your GitHub repository, open the existing index.html.
2. Choose Edit (pencil) or Add file > Upload files. Replace index.html with this file.
3. Commit to the main branch.
4. Wait for GitHub Pages to publish, then refresh the live site.

All 12 artwork images are embedded in index.html; no assets folder is required.
This is a 2D browser RPG prototype. Test on your phone after publishing.
